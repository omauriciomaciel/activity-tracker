# Data Sources

The four activity capture sources feeding the [Collector Service](../services/collector.md).

* [Shell History](shell-history.md) - incremental reads of Bash, Zsh, and Fish history
* [Open Windows](open-windows.md) - multi-platform window-title capture (wmctrl/xdotool/osascript/ps/WSL)
* [Browser Tabs](browser-tabs.md) - Chrome/Brave via DevTools Protocol or SQLite history
* [Git Context](git-context.md) - per-repo commits for the current day
